Xiamoi

cg_changeid — Change CyberGear Motor ID

A host-side utility to change the CyberGear motor ID on a CAN bus.

Usage

go1_changeid [tty device] [id] [target_id]

Examples:

  • cg_changeid /dev/ttyUSB0 0 1 → Change motor with ID 0 to ID 1

Notes

  • No duplicate IDs may exist on the same CAN bus.
  • Verbose logging for motor commands is always enabled.
  • On success, prints SUCCESS. On failure, prints errors.

Unitree

go1_changeid — Change Unitree Go1 Motor ID

A host-side utility to change the Unitree Go1 motor ID on an RS-485 bus.

Usage

go1_changeid [tty device] [id] [target_id]

Examples:

  • go1_changeid /dev/ttyUSB0 0 1 → Change motor with ID 0 to ID 1
  • go1_changeid /dev/ttyUSB0 15 1 → Change all motors to ID 1 (use with caution!)

Notes

  • Motor broadcast ID is 15.
  • No duplicate IDs may exist on the same RS-485 bus.
  • The tool forces the motor into boot mode before sending the ID change.
  • Verbose logging for motor commands is always enabled.
  • Baud rate: 4 Mbps on the specified serial device.
  • On success, prints SUCCESS. On failure, prints errors.

Unitree

go1_scanbus — Scan Unitree Go1 Motors

A host-side utility to scan the RS-485 bus for Unitree Go1 motors. It iterates through motor IDs (0–14) or a user-provided ID and reports any responding motors.

Usage

go1_scanbus [tty device] [id]

Examples:

  • go1_scanbus /dev/ttyUSB0 → Scan all IDs 0–14
  • go1_scanbus /dev/ttyUSB0 5 → Probe only ID 5

Notes

  • Broadcast ID is reserved as 15 and not scanned.
  • Each responding motor returns its ID via feedback.
  • Mismatched responses are logged as warnings.
  • Baud rate: 4 Mbps on the specified serial device.
  • Verbose motor logging is always enabled.

Unitree

a1_changeid — Change Unitree A1 Motor ID

Interactively change the Unitree A1 (UkiA1) motor ID on an RS-485 bus. This tool broadcasts to all motors, switches them to FOC mode, then to “change-ID” mode. You physically move the target motor a number of detent notches to select a new ID, then confirm.

Usage

a1_changeid [tty device]
# example:
a1_changeid /dev/ttyUSB0

During the prompt:

  • Move the motor to select the ID:
    • 1 notch → ID 0
    • 2 notches → ID 1
    • 3 notches → ID 2
  • Press **'a'** to apply and finish.

Notes

  • Valid IDs are 0–2 for this mechanism.
  • There cannot be duplicate IDs on the same RS-485 bus.
  • Verbose motor logging is enabled by default.
  • Bus: RS-485 @ 4.8 Mbps.
  • Prints SUCCESS on completion.

Unitree

a1_scanbus — Scan Unitree A1 Motors

A host-side utility to scan the RS-485 bus for Unitree A1 (UkiA1) motors. Sends FOC-mode commands to candidate IDs in range 0–2 and checks for responses.

Usage

a1_scanbus [tty device] [id]
# example:
a1_scanbus /dev/ttyUSB0
  • With no [id] specified, the tool scans IDs 0 through 2.
  • With [id], scans only the given motor ID (must be 0–2).

Notes

  • Bus: RS-485 @ 4.8 Mbps.
  • Verbose logging is always enabled.
  • On success, prints Found ID: <id> for detected motors.
  • Warns if response ID does not match expected.
