API (Protocol Buffers)

PuddleDuck wire protocol.

Names are fully-qualified under the package pd.api .

Commands → PuddleDuck

Messages the host sends to the robot.

CommandWrapper

Top-level envelope for a single command. Exactly one field of the oneof is set.

oneof command

  • PolicyStart policy_start (field=1) — Start a policy controller loop.
  • PolicyAction policy_action (field=2) — Send a concrete policy action.
  • JointMoveRadians joint_move_radians (field=3) — Direct joint targets (radians).
  • FlashlightCommand flashlight_cmd (field=4) — Toggle flashlight.
  • JointZeroRef joint_zero_ref (field=5) — Provide/override joint zero references and ranges.

PolicyStart

Start a policy controller and begin streaming observations (see ResponseWrapper).

Fields:

  • string name (1) — Policy name to start.
  • double dt (2) — Observation step (seconds). Use 0 for default rate.

PolicyAction

A policy controller’s action specifying desired joint targets and optional gains.

Fields:

  • string name (1) — Policy name this action applies to.
  • double duration (2) — Time in milliseconds to reach targets (0 for immediate set).
  • repeated double joint_radians (3) — Target angles (radians) for joints in policy name.
  • repeated double joint_kps (4) — Optional per-joint KP overrides (else config defaults).
  • repeated double joint_kds (5) — Optional per-joint KD overrides (else config defaults).

JointMoveRadians

Direct motor command in radians (bypassing a higher-level policy).

Fields:

  • repeated double radians (1) — Per-joint target angles (radians).

FlashlightCommand

Simple device control for a flashlight.

Fields:

  • bool on (1) — true to turn on, false to turn off.

JointZeroRef

Provide or update joint zero references and joint ranges for a named policy layout.

Fields:

  • string name (1) — Policy reference name that defines joint order.
  • repeated double zero_ref (2) — Per-joint zero offsets.
  • repeated double low_range (3) — Per-joint low (min) limits.
  • repeated double high_range (4) — Per-joint high (max) limits.
Note:\n Arrays should match the policy’s joint ordering. If a vector is
shorter than the policy’s joint list, unspecified elements retain prior values or defaults.

Responses ← PuddleDuck

Messages the robot sends back to the host.

ResponseWrapper

Top-level envelope for responses. Exactly one field of the oneof is set.

oneof command

  • Observation obs (1) — Periodic telemetry snapshot.
  • JointZeroRef joint_zero_ref (2) — Echo/report of current zero references and ranges.

Observation

Periodic telemetry produced while a policy is running (or when enabled).

Fields:

  • uint32 num (1) — Sequence counter.
  • uint32 timestamp (2) — Timestamp (source-specific units).
  • double cmd_lin_vel_x (3) — Commanded linear velocity X.
  • double cmd_lin_vel_y (4) — Commanded linear velocity Y.
  • double cmd_ang_vel (5) — Commanded angular velocity (yaw).
  • double roll (6), pitch (7), heading (8) — Orientation (radians).
  • Quaternion:
    • double quat_w (9), quat_x (10), quat_y (11), quat_z (12)
  • Gyroscope:
    • double gyro_x (13), gyro_y (14), gyro_z (15)
  • Accelerometer:
    • double accel_x (16), accel_y (17), accel_z (18)
  • Joints:
    • repeated double joint_angles (19) — Per-joint angles (radians).
    • repeated double joint_vel (20) — Per-joint velocities (rad/s).

JointFeedback

Lightweight joint state (used alongside direct joint commands).

Fields:

  • repeated double positions (1) — Joint angles (radians).
  • repeated double velocities (2) — Joint velocities (rad/s).

Enveloping & stream semantics

  • All traffic uses CommandWrapper (host→device) and ResponseWrapper (device→host) envelopes with a single oneof payload set.
  • PolicyStart enables periodic Observation frames at rate dt (or a default if dt==0).
  • PolicyAction affects joints enumerated by the named policy; vector lengths must align with the policy’s joint order.
  • JointZeroRef is both a command (override) and a response (report), depending on direction.
